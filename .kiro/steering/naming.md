# Naming Rules

## Components

- Use PascalCase; file name must match component name (e.g. `BibleVerseCard.tsx`).

## Hooks

- Must start with `use`, camelCase (e.g. `useResponsive.ts`).

## Screens

- Must end with `Screen` (e.g. `BibleScreen.tsx`).

## Services / Stores / Contexts

- End with `Service`, `Store`, or `Context` respectively.

## Variables

- camelCase, descriptive names.

## Booleans

- Prefix with `is`, `has`, `can`, or `should`.

## Constants

- `UPPER_SNAKE_CASE` only for global constants.
